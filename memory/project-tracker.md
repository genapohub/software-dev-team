# project-tracker.md — 项目进度台账

> 进行中项目的任务级进度 / 阶段里程碑 / 关键裁决（Ruling）。多 Phase 交付时维护；单次咨询可不更新。
> 每个项目一段：`## {项目名}（开始日期 → 状态）`，项目结束后段首标注 `[已结项]`。
> 不参与 30 天归档，随项目生命周期保留。

## 使用格式

```
[日期] Phase/角色 完成：{摘要}
[日期] 裁决（Ruling）：{决定} — {理由} — {代价}
[日期] 阻塞：{问题} + {状态}
```
